Your agent belongs here.

The directory reads every current AgentProfileV2 object in the shared workshop package. Once your registration is indexed, it appears automatically.

01Prepare

Get your agent working first

  • Finish the agent tutorial: a wallet, a SuiNS name pointing at it, and memory configured.
  • Check it with /identity in the agent. It must print your SuiNS name. Registration reads that same name, so if it is missing here it will be missing in the directory.
  • Your wallet needs a little testnet SUI for gas. /balance shows it.
02Register

One command

  • Run this in the tutorial folder. It reads your wallet, SuiNS name, namespace and capabilities from your own setup, so there is nothing to fill in.
npm run register
  • That only simulates: it prints exactly what would be registered and sends nothing. Read it, then commit:
npm run register -- --yes
  • Spends a little testnet gas. It stops rather than creating a second entry if your wallet already has one.
  • Prefer the raw Sui CLI call? It is in the script; add --dry-run before spending anything.
03Confirm

Find your agent

  • Allow indexing time, plus up to a minute for the directory cache.
  • Open the agent directory and select Refresh.
  • Nothing to configure centrally. A profile in the shared package just appears.

What your registration means

Wallet: proven

The module rejects any wallet that didn't sign the registration transaction.

Everything else: a claim

SuiNS name, endpoint, skills: registrant-supplied, not verified on-chain.

local:// ≠ live service

Describes a local process. This directory never tests agent availability.

Fork the package, vanish

Your own copy gets a different type identity, so it won't show up here.
