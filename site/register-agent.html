01Prepare

Prepare your agent

  • Follow the agent tutorial to create your local wallet and configure OpenRouter, SuiNS and Walrus Memory. Registration below is a separate Sui CLI step.
  • Use a testnet Sui CLI signer that you control and fund it for registration gas. The tutorial wallet is stored separately in .data/agent-wallet.json; it is not automatically your CLI signer.
  • The command below registers whichever wallet the CLI is signing with. To register your tutorial wallet, import its key into the CLI and switch to it, then confirm the active address matches the one the agent reports for /identity. Use a SuiNS name that targets that address, and your configured memory namespace.
cd suibasecamp
# read the agent's key out of its wallet file and import it
sui keytool import "$(node -p "require('./.data/agent-wallet.json').secretKey")" ed25519
sui client switch --address "$(node -p "require('./.data/agent-wallet.json').address")"
sui client active-address  # must match the agent's /identity address
  • The key reaches the CLI as a command argument, so it is briefly visible to other processes on the machine. That is acceptable for a testnet workshop wallet and nothing else.
  • Already signing with the agent's wallet? Skip the import; sui client active-address is the only check that matters.
02Register

Register with the common package

  • The wallet you register must be your active signer. The module checks it against the transaction sender.
  • Swap in your own metadata below. Keep the package ID unchanged.
  • Spends real testnet gas. Only declare capabilities your agent actually implements.
sui client switch --env testnet
AGENT_WALLET=$(sui client active-address)
sui client call \
  --package 0x73795ef21ec3554a141ddcf8d8b6696245762c8a071eeec4bbda2b0818f694c7 \
  --module agent_profile \
  --function create_v2 \
  --args "$AGENT_WALLET" \
    'myagent.sui' 'myagent' 'local://sui-local-agent' '2.0.0' \
    '["create_wallet","get_balance","resolve_suins","get_agent_suins_identity","remember","recall"]' \
  --gas-budget 10000000 \
  --json
  • Add --dry-run to the same command first. It simulates the call for free and prints the AgentProfileV2 it would create, so a wrong signer or a typo costs nothing. Drop the flag to register for real.
  • A wallet/signer mismatch aborts registration. Failed transactions may still consume testnet gas.
  • Save the created AgentProfileV2 object ID.
  • Don't re-run this just because the page hasn't refreshed. That creates a duplicate profile.
03Confirm

Find your agent

  • Allow indexing time, plus up to a minute for the directory cache.
  • Open the agent directory and select Refresh.
  • Nothing to configure centrally. A profile in the shared package just appears.

What your registration means

Wallet: proven

The module rejects any wallet that didn't sign the registration transaction.

Everything else: a claim

SuiNS name, endpoint, skills: registrant-supplied, not verified on-chain.

local:// ≠ live service

Describes a local process. This directory never tests agent availability.

Fork the package, vanish

Your own copy gets a different type identity, so it won't show up here.
